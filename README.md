# 🛍️ DukaanConnect

**DukaanConnect** is a responsive digital storefront prototype designed to help local shopkeepers establish an online presence, showcase products, and manage their catalogues easily.

🌐 **Live Demo:** https://snazzy-begonia-f64076.netlify.app/

## ✨ Features

- 🏪 **Digital Storefront** — Display products in a customer-friendly interface.
- 📦 **Product Management** — Add, edit, delete, and manage product availability.
- 🔍 **Category Filtering** — Browse products by category.
- 🛒 **Shopping Cart** — Add items, update quantities, and calculate the total price.
- ⚙️ **Shop Profile Management** — Customize shop information and details.
- 👨‍💼 **Admin Dashboard** — Demo interface for shop onboarding.
- 💾 **Local Storage** — Save product and shop profile data in the browser.
- 📱 **Responsive Design** — Designed for desktop and mobile screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 Getting Started

1. Clone this repository:


2. Open the project folder.

3. Ensure `index.html`, `styles.css`, and `script.js` are in the same directory.

4. Open `index.html` in your browser to explore the application.

No additional installation or build tools are required.

## ⚠️ Current Limitations

This project is currently a front-end prototype.

- Product and profile data are stored locally in the browser.
- Data is not synchronized across different devices.
- The QR preview is decorative and is not a functional, scannable QR code.
- Orders are demonstrated in the interface but are not submitted to a real shopkeeper.
- Backend, database, authentication, and payment integrations are not implemented.
- Admin onboarding submissions are not permanently stored.

## 🔮 Future Improvements

- Integrate a backend and shared database.
- Generate functional QR codes for individual shops.
- Implement user authentication and shopkeeper accounts.
- Enable real-time product catalogue updates.
- Implement order management and notifications.
- Integrate online payment options.
- Deploy a complete multi-shop platform.

## 🎯 Project Objective

The goal of DukaanConnect is to explore how small local businesses can establish an online presence through a simple digital storefront, making it easier for customers to discover and browse their products.
